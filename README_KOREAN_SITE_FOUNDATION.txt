KOREAN SITE FOUNDATION SPRINT

This package:

1. Removes visible EN and KR text from the header.
2. Leaves only the globe icon at the far right.

4. Links Korean pages back to /.
5. Adds a Korean homepage using the current film and paper-room design.
6. Adds Korean route shells for all six main sections.
7. Keeps the English site unprefixed.
8. Keeps static export compatibility.

No server runtime or additional package is required.
