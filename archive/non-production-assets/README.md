# Non-production asset archive

These files are retained in Git for provenance, rollback, and future brand/media work, but are intentionally kept outside `public/` so they are not copied into the current static website export.

Archive criteria:

- no current production source reference;
- superseded by a live delivery derivative or exact duplicate; and
- not required by the current page-cover manifest, Open Graph metadata, Apple touch icon, or reserved future-app path.

Do not restore an archived file to `public/` unless a production route, metadata surface, or documented asset role requires it.
