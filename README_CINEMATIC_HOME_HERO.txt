CINEMATIC HOME HERO SPRINT

Apply this package only when the local main branch is clean and up to date.

The package:
- adds the supplied opening film as a full viewport homepage hero
- overlays the existing header on the video
- changes homepage navigation text to warm ivory
- recolors the transparent navy wordmark to gold with CSS on the homepage only
- preserves the existing paper room content below the hero
- adds play and pause accessibility control
- adds reduced motion poster fallback
