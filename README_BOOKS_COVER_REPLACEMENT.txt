BOOKS COVER REPLACEMENT SPRINT

This package:
- replaces the previous hand-drawn BOOKS cover
- uses the approved reading-at-the-table image
- adds a desktop landscape cover and a portrait mobile cover
- adds optional mobileImage support to the shared PageCover component
- moves the BOOKS title to the right-side negative space

The package does not change any route, homepage film, navigation label, or other page cover.
