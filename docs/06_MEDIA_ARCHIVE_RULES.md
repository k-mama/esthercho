# Esther Cho Website — Media and Archive Rules

## Core Principle

Distinguish evidence, artwork, and reconstruction.

Approved labels:
- Original archival photograph
- Present-day photograph
- Original hand-drawn artwork
- AI-reimagined artwork
- Visual reconstruction based on memory

Never present an AI-generated image as an original historical photograph.

## Private Archive

Keep outside the public GitHub repository:
- original high-resolution scans
- private family photographs
- unapproved faces
- sensitive records
- legal documents
- master restoration files

## Public Repository

May include approved WebP/AVIF images, video posters, compressed public video, approved audio, captions, and transcripts.

## Living Photograph Rules

Allowed: slight camera push, moving light, moving curtain, moving leaf shadow, subtle depth, gentle weather outside the image space.

Not allowed: blinking, speaking, synthetic smiles, head turns, generated hugs, new gestures, identity changes.
