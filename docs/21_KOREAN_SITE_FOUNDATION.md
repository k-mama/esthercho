# Korean Site Foundation

## Route strategy

English remains the default unprefixed site.

- `/`
- `/stories/`
- `/books/`
- `/archive/`
- `/studio/`
- `/notes/`
- `/about/`

Korean uses the `/ko/` prefix.

- `/ko/`
- `/ko/stories/`
- `/ko/books/`
- `/ko/archive/`
- `/ko/studio/`
- `/ko/notes/`
- `/ko/about/`

## Header language control

Only the globe icon is visible.

No `EN`, `KR`, `KO`, or other language abbreviation is shown.

- On English routes, the globe opens `/ko/`.
- On Korean routes, the globe opens `/`.
- The language destination remains available through an accessible label and title.

## Scope of this sprint

This sprint creates:

- the Korean homepage
- Korean route shells for all six main sections
- Korean navigation labels
- Korean footer copy
- language-aware video controls
- route-aware document language handling

The long Korean biography and detailed Korean page bodies remain a later editorial translation sprint.
