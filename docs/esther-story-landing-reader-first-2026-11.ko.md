# 조성연 · 독자 중심 살아온 이야기 개편
날짜: 2026-11-22
범위: 한국어·영어 Stories 목록. 기존 원고 18편과 번호, URL은 전부 유지.

## 원고 근거
- 첫 장면은 01번 태몽과 아버지의 실제 농담을 사용. 원고의 인용문과 대조함.
- 추천 3편은 10번(찾아도 뜯지 못한 크리스마스 선물), 07번(아버지 사망 후에도 밥을 먹고 학교에 가는 자신에 대한 감정), 16번(아들의 정확한 영문 문장)으로 확정.
- 추천 카드의 헤드라인은 편집상 안내 문구이며 아들의 정확한 영어 문장 외에는 직접 발언이라고 가장하지 않음.
- 나머지 14편은 실제 장면과 기억 중심으로 분류, 기존 제목 그대로 보존. 08번 「행복을 모으는 사람」을 마지막에 배치하고 반복적인 대형 결론 섹션 삭제.
- 기존 #story-two 방문 링크가 실제 02번 식사 사진 이야기 행으로 이어지도록 보존.
- 개별 이야기 원고와 전체 사이트 홈은 이번 배포에서 수정하지 않음.

## 출시 검증
- 한국어·영어 각각 중복 없는 18개 글 주소를 확인.
- 정적 빌드 및 문법 검사 통과 필요.
- 공개 페이지, 기존 URL, 식사 사진 및 아들 실제 사진의 보존 확인.
- 실제 모바일 줄바꿈과 키보드 동선은 브라우저에서 가능한 범위로 검사.
