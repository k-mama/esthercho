# 조성연 홈페이지 — 인생 이야기 구성 편집 반영 기록
일자: 2026-11-21

## 실제 반영
- 어린 시절 앨범의 사진 관련 추상적인 안내 섹션 2개 삭제.
- 한국어·영어 18편의 기존 원문과 번호는 유지하고, ‘가장 행복했던 집 / 그해 7월 / 이제 내가 차리는 식탁 / 행복을 모으는 사람’ 네 흐름으로 추천 읽기 순서 편집.
- 장식적인 8단계 연대표와 중복되는 ‘기억을 데려온다’ 섹션 삭제, 실제 이야기 링크로 대체.
- 02번의 57장 실물 사진을 독립 페이지로 이동. 처음 9장, 더 보기마다 12장 방식 유지. 과거 #story-two 링크도 새 글로 연결.
- 16번에 작가와 아들이 해먹에 있는 사진, 웃는 아들, 비눗방울을 부는 아들 사진을 추가. 해당 사진들이 아들의 정확한 발언 장면을 담았다고 주장하지 않음. 책에 인쇄되지 않은 작가의 별도 창작 메시지도 구분 유지.
- 메인 화면의 그림책 영상 노출을 3개에서 1개로 축소, 나머지 영상은 책 페이지에서 보존.
- 작업실의 빈 안내 문단 삭제, 메인의 추상 문구 압축, 아침 식탁에는 실제 묵상을 먼저 배치.
- 기타 8개 언어 페이지에서는 예전 7편이 완료된 것처럼 보이던 목록을 제거, 실제 제공되는 01·03번 번역 발췌문과 한국어·영어 18편 링크를 표시.
- 번역되지 않은 개별 이야기에 대한 언어 전환은 해당 언어의 이야기 목록으로 안내, 존재하지 않는 URL 방지.

## 보존 및 주의
- 작가의 직접 구술에 없는 연대·감정·사진 장면·책에 인쇄됐다는 주장을 임의로 만들지 않음.
- 기존 이야기 번호는 바꾸지 않음. 추천 순서는 연대순과 다름.
- 청담동 가족사진 AI 편집본은 편집 사실을 계속 표시하고, 원본은 공개 저장소에 올리지 않음.
- 18편의 다른 언어 정식 번역은 각 언어별 번역 가이드에 따라 별도로 진행해야 함.
- 브라우저 자동 클릭·모바일 화면 검수는 도구 사용 제한으로 미완료. GitHub CI, 공개 텍스트 및 이미지 주소 점검으로 대체.
