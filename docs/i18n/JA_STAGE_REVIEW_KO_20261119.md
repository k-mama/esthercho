# 일본어 홈페이지 — 단계별 내부 검수
기준일: 2026-11-19 | 비공개 브랜치: feature/multilingual-foundation-20261118

**제작:** 일본어 메인과 6개 공간, 실제 이야기 두 편 전체 번역(*父は虎の夢を見た*, *どの家でも末娘*)을 완성했다. 작가 실제 인물 사진, 어린 시절 기록 사진, 기존 홈페이지 영상과 그림책 홍보영상은 그대로 보존했다. 석사과정 이수·수료와 학위 취득을 구분했고, 확인되지 않은 일본어판 그림책 판매 링크를 만들지 않았다.

**일본어 글꼴 문제 해결:** 최초 비공개 화면에서 상단 메뉴의 일부 글자가 네모(□)로 나타났다. 언어 선택기에 숨겨진 한국어 옵션이 공통 CSS의 한국어 감지 조건을 잘못 작동시키는 것이 원인이었다. 이를 **실제 페이지가 한국어일 때만 적용**하도록 수정하고 일본어 전용 Noto 글꼴과 기기 기본 글꼴을 지정했다. 일본어·한국어 화면을 다시 검수했다.

**기술 검수:** 일본어 9/9 페이지 자동 검사를 통과했고 전체 70개 페이지의 통합 SEO·주소·미디어 검사도 통과했다. 일본어 비공개 화면 검사 `44354257510`은 성공했다.

**미완료:** 일본어 원어민 독립 교정, 실제 기기에서의 글꼴·메뉴·키보드·구매 링크 검수, 통합 화면 최종 검수. 정식 공개는 하지 않았다.
