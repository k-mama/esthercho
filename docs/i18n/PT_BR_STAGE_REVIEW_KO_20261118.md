- 실제로 읽을 수 있는 이야기 두 편 전체: **Meu pai sonhou com um tigre(아버지는 호랑이 꿈을 꾸었다)**, **A caçula em cada casa(가는 집마다 막내딸)**. 소개 페이지와 작품 사이의 이동까지 연결했다.
- 상단 메뉴·보조 메뉴·푸터·언어 선택기·링크 문구와 사진 대체 설명의 현지화.
- 작가의 실제 인물 사진과 기록 사진은 보정하거나 새로 생성하지 않고 보존했다.
- 기존 그림책 홍보영상 세 편과 그림책 표지, 실제 아침 식탁 사진, 묵상집 표지 검토 자료를 유지했다.
- 실제 출간된 **영어 그림책**과 **독일어 종이책**으로 연결했다. 아직 출간되지 않은 묵상집이나 브라질 포르투갈어 그림책이 판매 중인 것처럼 표시하지 않았다.

- `/pt-br/` 주소, HTML 언어 `pt-BR`, SEO 메타데이터·정규 URL·사이트맵·언어별 대체 URL을 정비했다.
- 영어와 포르투갈어에서 공개된 이야기 두 편은 언어를 바꿔도 **동일한 작품으로 이동**하도록 구성했다.
