기준일: 2026-11-19 | 브랜치: feature/multilingual-foundation-20261118 | **미배포**

**번역 기준:** 기존 영문·국문 홈페이지의 기록을 원문 기준으로 삼았다. 첨부된 독일어 마스터 번역 가이드 v2.5를 직접 읽고 *Klar, ehrlich, geistlich ruhig, emotional kontrolliert* — 명료하고 정직하며 과장 없이 차분한 문체를 적용했다. 아직 출간되지 않은 묵상집의 본문은 홈페이지에 공개하지 않았다.

**완료:** 독일어 기본 7개 공간, 실제 가족 이야기 전체 번역 2편(*Mein Vater träumte von einem Tiger*, *Überall die Jüngste*). 실제 작가 사진·어린 시절 가족 사진은 변경하지 않았다. 메뉴, 사진 대체 설명, 생애 연표와 학력(1985·1988·1992·1999), 홍보영상 3편을 보존하고 현지화했다. 1999년 석사과정 **교과목 수료**를 학위 취득처럼 표현하지 않았다.

**도서 구매:** 독일어 종이책 *Große Träume in allen Farben*(Amazon.de ASIN B0HRS6F2MH)을 먼저 보여주고 실제 표지를 연결했다. 영어판은 뒤에 배치했다. 같은 독일어판의 중복 상품 소개는 없앴다. 확인되지 않은 독일어 Kindle 상품 주소를 지어내지 않았다. *Manna on the Table*은 집필 중이라고 명시했다.

**검사:** 독일어 9/9 페이지 자동 검사, 전체 70페이지 통합 검색·주소·미디어 검사가 성공했다(GitHub `44365004495`). 독일어 PC·모바일 미리보기에서 작가 실제 사진과 페이지 배치를 확인했다(`44365004366`). 독일어 종이책의 실제 아마존 표지 로딩도 **통과**했다. GitHub 비공개 브라우저 검사 `44365696373`에서 원본 표지 1000×1499px가 정상적으로 나타났고, 독일어 제목과 구매 링크도 확인했다.
