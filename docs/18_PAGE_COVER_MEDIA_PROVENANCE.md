# Page Cover Media Provenance

The six page covers use supplied real photographs or Esther Cho's original hand-drawn work.

Processing applied:

- EXIF orientation correction
- EXIF metadata removal
- RGB conversion
- proportional resize
- JPEG optimization
- no generative reconstruction
- no face replacement
- no background replacement
- no invented archive detail

The childhood cover uses the specific garden photograph selected by Esther Cho's sister.
