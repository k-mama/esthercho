# 07번·11번 원고 대조 및 이동 문구 검수
날짜: 2026-11-22

원전: 『내가 좋아하는 것들과 내가 사랑하는 삶』 §§7–9 및 『조성연 작가의 어린 시절과 기억』 §§17–23.
조성연 작가 구술·회고를 우선으로 하며, 없는 사건·심리를 만들어 보태지 않는다.

## 확인한 실제 연혁
- 입시 미술 공부 시작: 초등학교 4학년 무렵, 어머니의 결정.
- 아버지의 죽음: 예원학교 중학교 1학년 7월.
- 서울예술고등학교와 서울대학교 미술대학 진학: 그 이후.
- 아버지의 죽음 이후 어머니를 돌봐야 한다는 생각이 생겼고, 그 마음이 성인이 된 후에도 이어졌다고 작가가 직접 회고함.

## 반영 내역
- 07번 영문 소개에서 원전에 없는 '아침 식사(breakfast)'를 삭제. '밥을 먹고 학교에 갔다'의 시간 특정 없는 의미로 복원.
- 07번 한국어·영어 본문에 원전의 '지금까지도 엄마를 돌봐야 한다'는 지속성 한 문장 복원.
- 07번에서 11번으로 이동할 때 시간상 거슬러 올라가는 구성임을 설명. 예술 공부를 아버지의 죽음으로 인해 시작했다고 오해시키지 않음.
- 11번에서 02번으로 이동할 때는 '성인이 된 뒤의 식탁'으로 다음 시간대를 명시.
- 다른 16편, 기존 기사번호·슬러그, 사진/도서 페이지는 손대지 않음.

## 검증 한계
기존 GitHub Actions Lint·Production Build와 소스 정합성 검증만 사용. 별도 유료 도구·충전은 사용하지 않음.
실제 모바일 기기의 터치·스크롤·이미지 확대는 별도 실기기 검수가 남아 있음.
